## اختر طريقة اللعب

- **كلاسيكي:** الحكم يدير توزيع الأدوار والليل والنقاش والتصويت من جهازه.
- **تفاعلي عبر QR:** اللاعبون يفتحون رابط الدعوة أو يمسحون الرمز، ويختارون مقاعدهم. بعد موافقة الحكم تظهر بطاقاتهم السرية وقدراتهم وتصويتهم في المتصفح، دون تنزيل تطبيق أو إنشاء حساب للاعب.

## ميزات التطبيق

| الميزة | ما تقدّمه |
| :--- | :--- |
| إدارة الجولات | كشف للأدوار، اغتيال وحماية وتحقيق وإسكات، ثم نقاش وتصويت ودفاع وحسم. |
| مؤقت النقاش | إيقاف واستئناف وتمديد الوقت من شاشة الحكم. |
| قوانين قابلة للتخصيص | شرح لكل إعداد، وحدود للقدرات وخيارات لشروط الفوز. القناص قدرة إضافية لأحد المواطنين، بطلقة واحدة يمكن تأجيلها. |
| صالة الانتظار | QR قابل للتكبير، نسخ رابط الانضمام، متابعة المقاعد وقبول الطلبات أو رفضها. |
| صحيفة المدينة | تسلسل للأحداث مع التمييز بين ضحايا المافيا والقنص ونتيجة المباراة. |
| سجل وإحصائيات | تقارير المباريات وإحصائيات اللاعبين. حذف مباراة يمحو بياناتها مع إبقاء الإحصائيات الإجمالية. |
| استعادة الجلسة | متابعة المباراة بعد خروج غير مقصود، والعودة لنفس الشاشة عند التنقل لتطبيق آخر. الإنهاء اليدوي ينهي الجلسة. |
| حساب وإعدادات | ملف شخصي، أسماء لاعبين محفوظة، تخصيص أسماء الأدوار والصوت والثيمات. |

**أدوار المدينة:** شيخ المافيا، بنت المافيا، مافيا؛ شيخ المواطنين، بنت المواطنين، المواطن الشجاع، مواطن صالح؛ والجوكر المستقل.

## أجواء اللعبة وPremium

الأحمر الدموي هو الثيم الأصلي المجاني. من **الإعدادات ← الثيمات** توجد ثلاث مجموعات حصرية: منتصف الليل، النادي الزمردي، والجناح الملكي. استخدامها يحتاج صلاحية Premium؛ **الشراء داخل التطبيق لم يُفعّل بعد**.

**AI Voice Assistant** مخطط له ضمن Premium، ويظهر حالياً كمعاينة في إعدادات القواعد؛ لا يعمل بعد.

## ابدأ السهرة

1. نزّل APK وثبّته على هاتف الحكم. اسمح بالتثبيت من مصدر التنزيل عند طلب Android.
2. أضف اللاعبين، اختر الأدوار وراجع القوانين.
3. العب كلاسيكياً، أو شارك QR/رابط الجلسة ووافق على انضمام اللاعبين.
4. أدر الجولات، ثم راجع النتيجة والصحيفة والإحصائيات.

إدارة الجولات الكلاسيكية تعمل محلياً. تسجيل الدخول وحفظ النتائج ومزامنة الحساب تحتاج الإنترنت، وكذلك اللعب عبر QR.
