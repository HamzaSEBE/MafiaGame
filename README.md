## ✨ الميزات الرئيسية (Features)

| الميزة | الوصف |
| :---: | :--- |
| 🎬 **أصوات سينمائية** | مؤثرات صوتية تزيد من حماس اللعبة وتعطي طابعاً غامضاً ومثيراً (Cinematic sounds) |
| 📊 **إحصائيات اللاعبين** | متابعة دقيقة لأداء كل لاعب وأدواره عبر جولات متعددة (Player stats) |
| 📰 **صحيفة اليوميات** | سجل زمني للأحداث اليومية للرجوع لها وكشف الحقائق (Newspaper timeline) |
| 📴 **لعب بدون إنترنت** | لا حاجة للاتصال بالإنترنت، استمتع باللعبة في أي مكان (Works offline) |
| 💎 **واجهة زجاجية** | تصميم عصري وجذاب بتقنية (Glassmorphism UI) لراحة العين وسهولة الاستخدام |

## 🎮 عن اللعبة (About)

تطبيق **مافيا عالشوارب** هو المساعد الأول لمدير اللعبة (Game Master) في لعبة المافيا الشهيرة. يوفر التطبيق واجهة سلسة لتوزيع الأدوار، تتبع الأحداث الليلية والنهارية، وضمان سير اللعبة بدون أي أخطاء بشرية من قبل الإدارة. استمتع بأجواء مليئة بالشك والمؤامرات مع أصدقائك!

> "أفضل طريقة لإدارة لعبة المافيا بدون أن يضيع الحماس!"

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **الإطار:** [Flutter](https://flutter.dev/)
- **اللغة:** [Dart](https://dart.dev/)
- **الخطوط:** `Cairo` لدعم ممتاز للغة العربية.
