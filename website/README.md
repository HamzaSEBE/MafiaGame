# موقع مافيا عالشوارب

موقع عربي RTL ثابت، بدون مكتبات أو خادم أو أدوات بناء ثقيلة.

**الموقع:** https://mafia-alshawareb.wavygrass32.chatgpt.site/

```bash
python3 website/build.py
node --check website/app.js
```

يبني السكربت `website/dist` بعد فحص الروابط والأصول وبيانات APK. تُنشر ملفات `dist` عبر Sites باستخدام هوية المشروع المحفوظة في `.openai/hosting.json`؛ هذا المجلد ليس بديلاً عن نسخة Flutter Web الخاصة بجلسات QR على Firebase Hosting.

- مصدر التنزيل: أحدث APK مرفوع في `releases/` بالمستودع الرسمي، وليس رفعاً مستقلاً يتأخر عن النسخة المعلنة.
- عند تحديث APK: حدّث `release.json` وروابط النسخة ووصفها في `index.html` ثم أعد الفحص والنشر.
- `assets/app-icon.png` نسخة مطابقة لأيقونة Android الأصلية. الرسوم من أصول اللعبة والخط Cairo مع ترخيصه OFL.
- اختيار الدور والثيم والقائمة يعمل بـJavaScript خفيف؛ المحتوى الأساسي والتنزيل والأسئلة يعملون بدونه.
- لا تحليلات أو حسابات أو ملفات تعريف ارتباط تسويقية في كود الموقع.
- لا تشغّل متصفحاً أو محاكي Android للاختبار على جهاز التطوير محدود الذاكرة.
